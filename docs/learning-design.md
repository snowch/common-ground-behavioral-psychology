# Learning design

Audience: interested adult beginners who want to interpret human behaviour using evidence. The gap is between attaching an intuitive label and explaining a case with accurate concepts, alternatives and limits. Delivery is a standalone, accessible, learner-paced GitHub Pages course, not an LMS or certification.

The established café visual identity uses Libre Baskerville headings, Arimo body text, pale blue backgrounds, navy text, teal interactions and restrained chapter accents. Reading and controls precede the supporting figure in the stacked layout. The primary learning path remains clear when research disclosures stay closed.

Each chapter has a first decision, three separate narrated explanations, a visible evidence check, a new written transfer case, unaided retrieval and low-stakes field practice. The final case integrates chapters. Page visits indicate navigation, not mastery. No learner pilot or independent academic review has been conducted.

## 1. Describe the action before explaining it

Objective: Operationally define a behaviour and distinguish a baseline from an explanation.

Initial decision: Which first step helps distinguish the explanations?

Transfer: One workshop records six missed returns and another records three, but the number of tool uses differs. What is missing?

Field application: Define one harmless action in your own routine. Record opportunities as well as occurrences, without collecting anyone else’s data.

## 2. A cue can predict what comes next

Objective: Identify the conditioned stimulus and response without confusing prediction with operant consequences.

Initial decision: Why is reward an imprecise label here?

Transfer: A bell occurs on some occasions. The team compares how often an event follows with and without the bell. Which cue is more informative?

Field application: Use a fictional everyday cue to identify an expected event and a possible learned response. State what comparison would test prediction.

## 3. Consequences can change an action

Objective: Classify reinforcement and punishment by their measured effects, distinguishing addition from removal.

Initial decision: If returns increase after the tone stops, what is the relation?

Transfer: A manager calls public praise a reinforcer, but has not measured subsequent participation. What must be checked?

Field application: Classify four fictional action-consequence examples using addition or removal and increase or decrease. Do not arrange consequences for real people.

## 4. Small steps can build a skill

Objective: Design successive approximations and distinguish skill acquisition from an access problem.

Initial decision: Which initial criterion fits Jo’s goal?

Transfer: A volunteer follows the procedure when equipment is available but cannot do so after the supplies are locked away. What should be changed first?

Field application: Choose your own harmless skill. Define one meaningful first step, a later criterion and an unprompted new example.

## 5. The pattern of consequences matters

Objective: Distinguish ratio and interval schedules while avoiding deterministic predictions about individuals.

Initial decision: What is missing from Leo’s exact prediction?

Transfer: After a set period has elapsed, the first eligible response receives the arranged consequence. Which schedule description fits?

Field application: Classify fictional consequence arrangements by response count or time. Identify a missing condition before predicting an effect.

## 6. A learned response can return

Objective: Explain extinction as new learning and distinguish response return from erasure failure.

Initial decision: What best explains the apparent contradiction?

Transfer: After a response decreases in one room, it returns when the cue is presented in a different room. Which research term fits most directly?

Field application: Use a fictional cue response to describe a context change and a delayed check. Do not run fear, deprivation or clinical exposure exercises.

## 7. A cue is not the whole situation

Objective: Distinguish generalization from discrimination and identify the conditions controlling an action.

Initial decision: What should Maya conclude first?

Transfer: A workshop wants learners to recognize the same safety instruction across several formats without applying it to unrelated labels. Which practice set best supports the intended skill?

Field application: Create two fictional examples of a harmless rule and one boundary case. Explain which feature matters.

## 8. Watching can teach more than imitation

Objective: Distinguish learning from a model, immediate imitation and later performance.

Initial decision: What would best test Jo’s learning?

Transfer: A learner feels confident after a demonstration but cannot yet complete the procedure independently. Which distinction matters?

Field application: Watch a public demonstration of a harmless skill. Name the useful relation and design a new case that would test it.

## 9. Habit depends on repeated contexts

Objective: Distinguish habit from intention and design a low-stakes change with a meaningful outcome.

Initial decision: Which account best fits the mug pattern?

Transfer: A person chooses a harmless routine but misses it when the context changes. What is the most useful next step?

Field application: Choose one harmless routine for yourself. Write an if-then plan, reduce one barrier and review opportunities without punishing missed attempts.

## 10. Change should be useful and freely chosen

Objective: Design an ethical behavioural evaluation that tests a meaningful outcome and preserves agency.

Initial decision: Which plan best fits the evidence and ethics?

Transfer: Agreed shelf changes improve returns during one workshop, but no later settings have been measured. What should the report conclude?

Field application: Write an ethical plan for a fictional routine: agreed goal, definition, baseline, support, comparison, follow-up and a right to decline.
